
# PostgreSQL Learning Journey

A practical repository documenting my journey of learning PostgreSQL and SQL.

I am learning by writing queries, solving exercises, fixing errors, and practising database concepts.

## Goals

- Learn PostgreSQL from basics to advanced.
- Practise SQL commands with real examples.
- Improve database and problem-solving skills.
- Build a strong foundation for Python Backend Development.
